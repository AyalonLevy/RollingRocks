# Rolling Rocks
This game is a submission to [Brackeys GameJam](https://itch.io/jam/brackeys-16).

This is a puzzle game where you have to push a rock to a hole (the target) however nothing is as it seems. The target is sometimes hidden and sometimes looks like something else.
Fortunately, you have a companion! ***Gepeto-A.I.*** is there to guide you through the puzzles and answer every query. It's not the most advanced A.I there is, but it's better then being alone.
Although, I have to admit, it's not the sharpest tool in the shad, so use it at your own risk!

Since souvenirs from places one visits are always nice, I've added useless junk that can be along the way and you could look at it later.
